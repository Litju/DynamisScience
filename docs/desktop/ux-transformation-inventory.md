Presentation state spans main-window perspectives, several nested stacks, panel-local controls, and per-data-root desktop settings. The service and stores own project/subject IDs, admitted sources, data/protocol/cohort/plan revisions, recorded observations, run eligibility, immutable runs and frozen reports. View changes must leave those contracts intact.

The native investigation capture on the disposable 20-athlete fixture showed a selected subject with no eligible dated pair, a legible LIVE revision, readable selected-visit detail, and overlapping actual-conduct labels. This instance used SUB-001, which is distinct from the owner-reported A01 fixture. The owner's RES-621 observations cover buried comparisons, mismatched context, limited evidence coverage, a confusing live/frozen round trip and dense import. The current run still needs matched A01 evidence, task timings, keyboard, high DPI, and unassisted acceptance.
